# EWEM Submission Hub

Academic portfolio for Tejas Pawar (24102B0033, TE CMPN B, Vidyalankar Institute of Technology).

Faculty can browse every EWEM submission, open or download each file, and launch the Andhra Pradesh dashboard in a new tab.

## Run

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Add the real files
